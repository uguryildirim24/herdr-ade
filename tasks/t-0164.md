  `herdr agent get hp-adeherdr-coordinator`; if it fails, `herdr agent rename "$HERDR_PANE_ID" hp-adeherdr-coordinator`.

  plugin. Run it again; that is the whole fix.
- Read `ha round merge`'s exit code directly, never behind a pipe.
- `ha thread prompt` to a reviewer right after `round advance` refuses until its brief arrives ("has not
  received its brief yet"); retry every 15 s. Review briefs list no gates, so send the cargo gates that way.

  zsh does not word-split `$var`.
