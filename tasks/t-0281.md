# W34: only Rolf's own messages count as his requests

Every message Rolf sends the coordinator gets a request id in `talk/journal.jsonl`, and
`--basis request:<id>` on `decide` treats that id as his authority. Three rows in the adeherdr
journal are not his:

- seq 695 (q-1790080328912-33802, 12:32:09Z) and seq 711 (q-1790082099393-72731,
  13:01:39Z) are messages from another coordinator session. Claude Code hands them to the
  prompt-submit hook wrapped as `<cross-session-message from="…" …>…</cross-session-message>`.
- seq 717 (q-1790082798125-91844, 13:13:18Z) is the ticker's continue nudge. It arrived
  wrapped in `<pasted_content id="2459">…</pasted_content id="2459">` and begins
  `[herdr-ade ticker: automated, not the user, approves nothing]`. A wrapped `DONE` line is
  already recognised (see the `hook.rs` test near line 755). This nudge was not.

`context` lists all three under "Latest messages from Rolf". So a peer's words could be cited
as Rolf's authority for a money or what-you-get choice.

## Change

1. `hook::handle_prompt` (`src/hook.rs`) records no request for a prompt that is a
   cross-session message (the whole prompt is that wrapper, possibly surrounded by
   whitespace). Treat it the way a `<task-notification>` is treated today.
2. Find why the wrapped ticker nudge was recorded while a wrapped `DONE` is not (the
   automated-prompt mark, `talk::mark_automated_prompt` in `src/talk/mod.rs` ~367, and how
   the nudge is marked and matched). Fix the cause so every ticker line typed into a pane,
   wrapped or not, is never recorded as Rolf's. Rolf's own text in the same prompt still
   records as his, as the mixed test near `hook.rs` line 803 shows.
3. Rows already in a journal: when reading requests (`talk::recent_requests`, the
   `--basis request:<id>` check, and `context`), apply the same rule. A stored row whose
   text is a cross-session wrapper or a ticker line is not Rolf's, so it isn't listed and
   can't be cited. Don't rewrite the journal.
4. Tests: a cross-session prompt records nothing; a pasted ticker nudge records nothing;
   an old journal row of either kind is left out of recent requests; and
   `decide --class money --basis request:<that id>` is refused.
